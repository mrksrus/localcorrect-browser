# Source and corpus license notices

This data is a templated synthetic test corpus, not a corpus of real adult messages. See the accompanying authoring README for dependence, split and gold limitations. Every document context and sentence frame is newly invented; original source stories and correspondence are absent.

Codespell typo-pair data derives from [codespell dictionary.txt](https://github.com/codespell-project/codespell/blob/b53e95197f7c799674c785028a182e2dfd1df881/codespell_lib/data/dictionary.txt), revision b53e95197f7c799674c785028a182e2dfd1df881. The dictionary derives from English Wikipedia and is [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). See the pinned [README](https://github.com/codespell-project/codespell/blob/b53e95197f7c799674c785028a182e2dfd1df881/README.rst). The subset selects only curated single-candidate alphabetic pairs and may adapt initial case. No codespell implementation is included.

German observed pairs derive from the [Litkey Corpus](https://linguistics.rub.de/litkeycorpus/), ISLRN 051-051-923-439-0, licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). [Official access/license](https://linguistics.rub.de/litkeycorpus/access.html). Archive: https://linguistics.rub.de/litkeycorpus/corpus/Litkey-csv.zip, SHA-256 6d8db45fa079c1dc6128e9e8db2d181c0fbcbb9d51693ebbc1ecb7785e2d649c. Cite Ronja Laarmann-Quante, Katrin Ortmann, Anna Ehlert, Simon Masloch, Doreen Scholz, Eva Belke and Stefanie Dipper, 2019, “The Litkey Corpus: A richly annotated longitudinal corpus of German texts written by primary school children”, Behavior Research Methods. This subset extracts only deidentified single-word errors and intended words, chooses adult vocabulary, rejects casing-only and known real-word relations, and may adapt initial case. No original sentence or source file identifier is retained.

Controlled keyboard mutations and invented sentence/email text are original synthetic contributions, separately offered under CC0 1.0. Their provenance labels distinguish them from observed public-source errors. The combined adaptation is CC BY-SA 4.0, with the original attribution and source license notices retained. Modified source pairs must not be described as unmodified original corpus records.

Public-source pairs may already occur in a runtime correction prior. Report overlap, correction coverage, missed edits and unintended edits separately. The dev/holdout split keeps intended target families apart, but both splits reuse authored templates. These fixtures cannot establish 99% precision on real-world text by themselves.
